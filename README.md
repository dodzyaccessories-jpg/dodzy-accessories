# Dodzy Accessories

This repository contains the storefront website, admin dashboard, and login page for Dodzy Accessories.

## Files
- `index.html` — customer storefront
- `Dodzy-Accessories.html` — alternate storefront version
- `admin.html` — admin dashboard
- `login.html` — admin login
- `assets/` — local SVG artwork and branding assets

## Admin email
- `dodzyaccessories3@gmail.com`

## Notes
This is a static demo storefront and admin dashboard. It stores cart and order data in `localStorage` for demo purposes.
